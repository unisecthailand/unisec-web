👨‍💻 รู้มั้ยว่า AI ไม่ได้เป็น tech เดียวที่ใช่บนอวกาศนะ

ในศาสตร์ของวิศวกรรมอวกาศแล้วนั้น หากเราจะออกแบบดาวเทียมสักดวงหนึ่ง เพื่อขึ้นไปทำภารกิจไม่ว่าจะเป็นเพื่อการสำรวจ หรือการทดลองนั้นมียากลำบากมากมายแน่ ๆ แต่แล้วอะไรหล่ะจะมาปฎิบัติภารกิจแทนมนุษย์ ?

คนมักจะนิยามคอมพิวเตอร์เป็นเด็กที่มีความสามารถด้านการคำนวณมาก ๆ แต่ก็โง่มาก ๆ ต้องรอคนอื่นมาสั่งตลอดเวลา มิเช่นนั้นมันเองก็จะไม่ทำอะไรเลย ดังนั้นมนุษย์เราจึงประดิษฐ์ AI ขึ้นมาเพื่อเพิ่มความฉลาดให้กับคอมพิวเตอร์ ผนวกกับสมรรถนะทางด้านการคำนวณเข้าไปอีก เราจึงได้สิ่งที่เปรียบเสมือนมนุษย์ แต่ประหยัดทรัพยากรมากกว่าและแถมยังขึ้นไปปฎิบัติภารกิจแล้วด้วยเช่นกัน !

💻 แน่นอนว่าเบื้องหลัง AI นั้นมันไม่ใช่แค่ If Else น่ะสิ มันมีองค์ประกอบมากมายซ่อนอยู่ในนั้น Machine Learning และ Deep Learning เป็นองค์ประกอบหลักในพัฒนา แต่ก็ไม่ใช่ว่า Machine Learning ผูกมัดอยู่กับ AI เท่านั้น เราสามารถเอา Machine Learning มาวิเคราะห์ หรือทำกราฟได้เพื่อจุดประสงค์และขอบเขตงานที่เล็กลงมาได้ ซึ่ง Machine Learning นั้นจะใช้ข้อมูลที่ป้อนให้ในการฝึกฝน

อีกสิ่งหนึ่งที่เรามักจะได้ยินในศาสตร์ของ AI กัน คือ Deep Learning ซึ่งเป็นระบบที่จะจำลองเปรียบเหมือนเซลล์ประสาทของมนุษย์การมาของสิ่งนี้ ทำให้เพิ่มขีดศักยภาพของ AI ได้อย่างมากมาย อย่างเช่น จำแนกชุดข้อมูลของน้องหมาพันธุ์ต่าง ๆ ได้, เข้าใจใจความสำคัญของโพสนี้, สร้างภาพใหม่ ๆ จากข้อมูลที่มี และอื่น ๆ อีกมากมาย

ทั้งหมดทั้งมวลที่กล่าวมาลองจินตนาการว่า ถ้าเราเอา AI, Deep Learning, Machine Learning มาพัฒนา และผสานเข้าไปในภารกิจทางอวกาศของพวกเรามันจะเจ๋งแค่ไหน ! ไม่ว่าจะเป็นการประมวลผลภาพที่ได้จากดาวดวงอื่นให้ชัดเจนยิ่ง ๆ ขึ้น, การนำข้อมูลที่เก็บมาจากการสำรวจมาทำนาย หรือวิเคราะห์เพื่อความรู้และวิทยาการใหม่ แล้วเพื่อน ๆ หล่ะคิดว่ามันเอาไปใช้สร้างอะไรได้บ้าง
